# 运维手册

每日信号、覆盖范围、配置与常用命令。研究设计与结果见 [README](../README.md)；调度与失败告警见 [调度设计](scheduling.md)。

## 每日信号

每个 A 股交易日，生产运行在 13:40–14:20 之间启动，先完成采集与评估，14:20 后生成报告并发送到 Telegram；报告生成与发送都受 14:20–14:55 时间窗约束，超出即失败告警，不发送过期建议。消息包含目标组合、单基金目标权重、操作方向和按账户估值计算的参考金额，并提示在 15:00 前完成买入/调整。

```text
🟢 第六届富国杯操作信号
2026-10-19 14:20｜策略 sector_rotation｜市场 risk_on
━━━━━━━━━━━━━━
① 买什么 / 调仓
1. 161024 富国中证军工A（军工）
   🟢 买入/建仓｜目标 35.0%｜参考 ¥70,000
2. ...
   🟠 减仓｜目标 10.0%｜卖出约 ¥20,000

② 为什么这么配
• 市场：risk_on，正趋势广度 100%
• 选基：行业 20 日动量前 2；行业内 60 日动量为正、综合评分前 3
• 约束：单基金≤35% / 单行业≤50% / 总仓位≤95%

③ 怎么执行
• 计划交易日：2026-10-19
• 截止：15:00 前按目标权重买入/调整
• 目标组合：合计 70.0%，现金 30.0%
• 参考金额按账户估值估算；限购/暂停申购以平台页面为准
• 研究信号，非成交指令；不提供可执行金额

④ 风险
• 历史区间已查看，不冒充前瞻；不保证收益
```

参考金额按账户估值和目标权重估算，不替代平台确认、费用和每日限购。正式下单路径会读取申购/赎回状态与限购金额并封顶；Telegram 参考金额用于判断量级，下单前以平台页面为准。

**假定执行。** 系统默认把上一份已发送信号的目标权重视为已执行：下一份信号按这个"假定持仓"给出加仓/减仓/清仓方向。设置 `ACCOUNT_JSON` 后以实际账户为准；实际成交份额或净值与建议不同时，方向可能偏离。手动测试消息不会成为假定持仓。

## 全量场外覆盖

分析范围覆盖富国旗下全部场外基金，不只限于可交易的支持池：

- 目录来自东方财富富国公司页（917 个代码）；排除场内 ETF、场内货币、REIT 和误链后为 808 只场外基金。
- 全部场外基金都会尝试采集净值，并逐只写入 `reports/universe_coverage.csv`，每只都有明确状态：`ok` / `insufficient_history` / `model_unsupported` / `error` / `not_requested`。
- 每日评分门槛为 128 条净值，完整回测门槛为 252 条。128–251 条的新基金可评分、可入选，但受 `new_fund_max_weight`（默认 10%）上限约束，并标注"无完整回测"。
- 买入候选另做可交易过滤：只有 `model_supported`、当前开放申购、且限购额足够最小下单额的基金才进入组合。QDII、FOF、货币、持有期、定开等仍会出现在分析清单和评分中，但不进入买入候选。
- 货币基金只覆盖、不评分（万份收益与净值口径不同）；采集失败显示为 `error`，并阻断正式报告。

## 热点观察哨

每日信号额外列出动量最强的主题和基金，**仅作提示，不买入**，也不改变目标组合：

- 主题按"最强基金 20 日动量 + 正动量占比"排序；基金按 20 日动量排序，同一基金组只留一个份额。
- 新基金（历史 <252 条）、模型暂不支持（QDII/FOF/货币等）、暂停申购的基金也会出现，并标注原因。
- 主题标签按关键词归类（如半导体、算力/通信、医药、军工、新能源、红利），只用于观察哨，不改变模型的 `sector` 与买入逻辑。

## 配置

| 字段 | 说明 |
|---|---|
| `competition.allowed_codes` | 比赛官方白名单；为空时研究模式使用自动发现的富国场外池 |
| `rules` / `fund_rules` | 费率、确认/赎回到账、最短持有、最小金额；正式模式须逐只核验并注明来源 |
| `signal.strategy` | 每日信号策略，当前为 `sector_rotation` |
| `signal.daily` / `signal.buy_deadline` | 每日信号与 15:00 执行截止提示 |
| `signal.assume_execution` | 默认 true：把上一份已发送信号视为已执行；设置 `ACCOUNT_JSON` 后以实际账户为准 |
| `universe.workers` | 采集并发数 |
| `data.max_nav_lag_sessions` | 允许的净值滞后；超过后报告阻断 |

账户文件：`config/account.example.json` 为空仓模板；`config/account.local.json` 为真实账户，已被 Git 忽略；云端使用 GitHub Secret `ACCOUNT_JSON`。

## 常用命令

```bash
fq doctor --limit 12        # 抽样请求公共接口，保存可审计证据
fq discover                 # 发现富国基金候选池（不等于比赛白名单）
fq collect                  # 采集净值与申赎状态
fq research                 # 固定方案滚动验证
fq report --research --account config/account.local.json
fq calendar-check --year 2027
fq validate                 # 检查比赛配置是否具备正式启用条件
fq --data data/expanded backtest --baseline-eight
```

GitHub Actions 手动运行 **Trading day reports** 时，`mode` 可选：`preview`（只生成报告，不发送）、`test-send`（发送带测试标记的消息，不占用当日时段）、`scheduled`（生产午后运行，供外部调度器调用）。
