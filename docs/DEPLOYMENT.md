# 部署、维护与验收

当前 `main` 即最终工程，生产工作流直接使用 main。工作流使用 GitHub 托管 Ubuntu（固定为 `ubuntu-24.04`）和 Python 3.12，不需要本地电脑开机。历史迁移记录仅见[迁移说明](MIGRATION.md)；不要按旧分支或旧账号命令操作。

## 配置步骤

1. 查看 main 的 Python3.11/3.12/3.13 检查、真实公开接口抽样和研究报告验收。抽样不是完整池回测；完整池本地验收证据见`sample_results/review/`。
2. 在本仓库的[Actions Secrets](https://github.com/auml168/FuGuoCup-quantsys/settings/secrets/actions)确认`TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`。实际模拟账户用`ACCOUNT_JSON`，不提交公开仓库。不要再把Token发到聊天；曾公开的Token应撤销重建。
3. 手动运行`Telegram connection test`确认通信。连接成功只代表Telegram接受消息，不证明本人已阅读、账户与平台一致或投资模型有效。
4. 在 `Trading day reports` 先关闭发送、启用研究模式做一次检查。非交易日会跳过；可用`Public data smoke test`在周末验收公开数据和研究流程。
5. 配齐比赛白名单和逐基金真实交易规则并更新实际账户。当前模型尚未得到部署批准，研究报告会明确不给交易金额；不能靠改`verified`或`deployment_approved`让系统看起来能交易。

## 发送预约与重复保护

原程序只串行运行作业，没有持久化去重。新流程如下：

1. 使用只读Actions权限，从同仓库、同可信分支的最近通知artifact恢复状态。拒绝fork来源；下载签名URL时不转发GitHub鉴权头。
2. 生成当前时段报告，并用稳定报告ID预约。同一时段已有预约或已发送则跳过；上一份可执行计划未核对则不重复给下单建议。
3. **先上传`notification-state-reserved`成功，再调用Telegram**。若上传失败，不发送交易报告。
4. 发送后保存`notification-state-final`。网络结果不确定时不盲目重试；保留预约，避免工作流重跑重复提醒交易。

这些artifact按run不可变，状态仅保存ID和哈希，保留90天并在运行中滚动继承。删除/过期/无法恢复状态时，正式执行条件不成立；不能拿空缓存当已核验状态。首次研究运行可建立无交易金额的通知状态。此设计优先避免重复交易提醒，不能保证消息一定送达或本人读到；失败须查看Actions并人工核对，不能绕过预约重新发旧指令。

公开artifact只上传通用研究、目录和快照；账户报告与outbox不上传，账户金额也不写入公开Actions日志。Token仅存在发送/故障步骤的环境变量，测试和研究步骤不拿Token。恢复状态需要`actions: read`，不需要内容写入权限或新增PAT。

## 实际账户

`ACCOUNT_JSON`示例见README。正式决策要求当日`as_of`和4小时内的带时区`reconciled_at`，并且没有在途资产。真实已确认批次单列`code`、`units`、`confirmed_on`；现金必须是平台可用现金，不含已占用申购款或未到账赎回款。不要同时把同一笔在途资产计入现金和份额。

实际成交后更新账户；未执行上一份计划时，核对后通过`acknowledged_plan_id`记录该计划已处理，不能仅刷新时间戳。系统无法读取比赛平台来证明这些输入真实，也不会把自己的建议伪装成成交记录。

## 故障与维护

- 采集失败/样本不足：查看`universe.json`和`snapshot.json`，不可用旧CSV补齐本次缺失。新基金历史不足属于明确排除，不是随机补值。
- 无法恢复通知状态：停止发送，检查Actions artifact、保留期限和权限。
- Token401、Chat ID/403：检查Secrets、`/start`和群权限。异常日志隐藏Token URL；429有界等待，网络超时不自动重发交易报告。
- 安装/回归测试/采集/发送失败：生产默认分支尝试发无金额故障消息。GitHub自身未调度任务、平台整体不可用或Token无效时，系统无法自发通知，应关注GitHub状态与失败通知。
- 公开仓库长期无活动可能停用cron，配额与排队也可能影响运行。云端不依赖本机，不等于无人维护或必定精确送达。
- artifact只保留有限时间；要长期复核研究，可定期下载归档。未建立完整历史退市目录、历史开放状态和发布版本前，不宣称样本偏差已消失。
