# 是否接入大语言模型

本次不增加LLM依赖、密钥或调用成本。当前最主要问题是目录、可用时间、交易规则、账户同步、费用和策略证据；LLM不能替代这些事实，也没有可核验的历史新闻样本证明加入模型能提高本项目净收益。

确定性报告已经能解释市场广度、动量、波动、仓位约束和阻断原因。新增LLM来改写相同数字只有表达上的潜在收益，尚无必要增加生产故障点。

未来值得单独试验的用途是：总结带原文链接与发布时间的政策/行业材料，列出信息与量化信号的冲突，生成可追溯的辅助研究摘要。应先取得合法可用的数据、保留当时版本，用冻结评价规则检验事实准确率、覆盖率、延迟和成本，不能用今天的新闻摘要重建过去“已知”的宏观判断。

即使后续试验通过，LLM输出也只能作为有来源的旁注。最终资格、风险上限、现金、份额、费用和金额仍由确定性代码计算；来源不足、内容过期或模型不可用时，报告可以省略摘要，不能影响安全检查。没有证据时不把文本情绪变成买卖指令。
