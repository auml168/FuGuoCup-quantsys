# FuGuoCup Quant

**富国杯场外基金量化研究与每日信号系统**

个人项目，独立完成数据采集、研究框架、回测引擎、组合构建与 Telegram 交付。
只覆盖富国基金旗下场外产品；每个交易日 14:20 生成目标权重，15:00 前由本人手动执行。

`Python 3.11–3.13` · `pandas` · `NumPy` · `unittest` · `GitHub Actions` · `Telegram Bot API`

## 项目摘要

| 维度 | 内容 |

## 核心工作

**候选池与数据**

- 从富国基金公司页自动发现产品，逐只打开详情页核验管理人 ID；排除 QDII、FOF、货币、黄金/商品、非联接 ETF、场内、持有期/定开/封闭、后端收费、期限/滚动/分级等产品。
- 解析单位净值、供应商日收益率、分红/拆分事件、申购/赎回状态与限购金额；原始响应和 CSV 均记录 SHA-256，支持从归档原始响应离线重建。
- 债券指数（Eastmoney “指数型-固收”）按债券处理；转债/混合一级/二级/偏债单独标记；A/C 等份额按名称分组，同一底层只保留一个份额。
- 对单位净值与供应商收益不一致且无事件解释的区间标记 `quality_break`。不回溯删除历史，断点后重新积累历史长度；持仓跨断点则整段回测判为不可验证。

**回测与账务**

- 自建事件驱动回测：T-2 信号、T+1 确认、T+3 赎回到账、FIFO 赎回费阶梯、最短持有期、最小金额、申购限额与现金/应收款逐日入账。
- 不使用第三方回测框架；费用、确认、到账、锁定份额和现金透支均由账本显式处理，禁止杠杆。
- 净值缺失、长缺失持仓、无净值成交、质量断点等异常按段记错；不用 0 收益或拼接收益填充指标。
- 研究区间 2021-01-04 至 2026-10-16；252 个观测初始训练、8 个 126 日滚动窗口、最后 126 个观测作为独立历史测试。

**策略与组合**

- 实现 9 个固定策略：等权、动量、相对强弱、行业轮动、择时、双动量、风险预算、ensemble、现金。
- 特征覆盖 20/60/126 日动量、20/60 日波动、120 日均线偏离、60 日回撤和风险调整动量；全部使用截面前缀，避免未来数据。
- 组合约束：单基金 ≤35%、单行业 ≤50%、总仓位 ≤95%、同一份额组只保留一只；剩余为现金。
- 默认信号策略 `sector_rotation`：按行业 20 日动量取前 2 个行业，再在行业内选 60 日动量为正、综合评分最高的至多 3 只基金。

**交付与工程**

- GitHub Actions 每日 14:20 采集、研究、生成目标权重并通过 Telegram 推送；08:30/20:30 触发但云步骤直接退出，避免重复采集。
- Telegram 发送前先生成持久化预约并上传 artifact，确认成功后才调用发送接口；同一时段重复运行不会重复发送。失败时发送无金额告警。
- 工作流日志和公开 artifact 不包含账户报告、outbox 或 token；账户金额在 Actions 日志中脱敏。
- 70 个回归测试覆盖时序、费用、结算、缺失数据、质量断点、账户、通知预约和信号文本；CI 覆盖 Python 3.11/3.12/3.13，另有真实公开数据 smoke test。

## 回测结果

2026-10-17 全量运行，最终测试区间 2026-04-10 至 2026-10-16：

| 策略 | 滚动验证 | 最终测试 | 最大回撤 | 夏普 |
|---|---:|---:|---:|---:|
| `sector_rotation` | +0.21% | **+1.20%** | 21.44% | 0.22 |
| `timing` | +21.18% | -6.13% | 18.70% | -0.60 |
| `risk_budget` | -6.96% | +0.37% | 10.23% | 0.12 |
| `equal_weight` | 无法验证 | -7.87% | 14.04% | -0.89 |
| `cash` | 0.00% | 0.00% | 0.00% | 0.00 |

要点：

- 9 个策略中只有 `sector_rotation` 在滚动验证和最终测试中同时为正；`timing` 滚动验证最高（+21.18%），但最终测试为负（-6.13%）。
- 等权基准在 2022-04-06 因持仓跨越无法解释的净值断点而无法可靠计价；系统保留该段为空，不拼接收益。
- 没有策略通过正式部署门槛，因此系统保持研究模式：不自动晋级、不产生可执行金额、不根据已查看的测试集改选赢家。
- 最终测试区间已经查看，不再算未见样本；历史结果不代表未来。

## 每日信号

只有 14:20 的定时任务会采集并发送。消息包含目标组合、单基金目标权重、操作方向和按账户估值计算的参考金额，并提示在 15:00 前完成买入/调整。

```text
第六届富国杯信号｜2026-10-19 14:20｜策略 sector_rotation｜市场 risk_on
目标组合（合计 70.0%，现金 30.0%）：
161024 富国中证军工A｜目标 35.0%｜买入/建仓｜参考 ¥70,000
...
信号截止 2026-10-15；计划交易日 2026-10-19。
研究信号，非成交指令；不提供可执行金额。
每日 15:00 前按目标权重买入/调整；参考金额按账户估值估算，非成交指令；不保证收益。
```

参考金额按账户估值和目标权重估算，不替代平台确认、费用和每日限购。正式下单路径会读取申购/赎回状态与限购金额并封顶；Telegram 参考金额用于判断量级，下单前以平台页面为准。

## 快速开始

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
python -m unittest discover -s tests -v

fq doctor --limit 12          # 真实接口有界验收
fq collect                    # 采集富国场外候选
fq research                   # 固定方案滚动验证

cp config/account.example.json config/account.local.json
fq report --research --account config/account.local.json
```

常用命令：

```bash
fq discover
fq --data data/smoke research
fq --data data/expanded backtest --baseline-eight
fq calendar-check --year 2027
fq validate
fq collect --competition
```

## 配置

| 字段 | 说明 |
|---|---|
| `competition.allowed_codes` | 比赛官方白名单；为空时研究模式使用自动发现的富国场外池 |
| `rules` / `fund_rules` | 真实费率、确认/赎回到账、最短持有、最小金额；正式模式逐只核验 |
| `signal.strategy` | 每日信号策略，当前 `sector_rotation` |
| `signal.daily` / `signal.buy_deadline` | 每日信号与 15:00 执行截止提示 |
| `universe.workers` | 采集并发，当前 8 |
| `data.max_nav_lag_sessions` | 允许净值滞后；超过后报告阻断 |

账户文件：

- `config/account.example.json`：空仓模板；
- `config/account.local.json`：真实账户，已被 Git 忽略；
- GitHub Secret `ACCOUNT_JSON`：云端使用的完整实际账户。

账户 JSON 支持现金、逐批已确认份额、在途申赎和上一份计划的核对状态。正式决策要求当日 `as_of`、4 小时内带时区的 `reconciled_at`，且无在途资产。

## 工程与自动化

- `.github/workflows/`：回归测试、真实接口 smoke test、每日报告；只有 14:20 的定时任务会采集和发送。
- 发送状态：恢复可信 artifact → 生成报告并预约 → 上传预约 artifact → 调用 Telegram → 保存结果；重复运行和超时不会盲目重发。
- 安全：Telegram/GitHub token 只从环境变量读取；异常信息隐藏 token URL；公开日志不打印账户金额。
- 2027 年官方日历未发布前保留未知日期拦截；日历解析失败时停止，不按普通工作日猜测。

## 限制与后续

- 候选池存在幸存者偏差；没有完整历史退市基金目录。
- 供应商净值是事后修订版；T-2 只缓解发布延迟，不能证明每个历史时点完全可得。
- 历史交易日使用国内权益参考净值日期代理；当前与未来操作必须通过官方年度日历。
- 费用、确认日、到账日和申购限额在正式模式下必须逐只核验；研究默认值只是假设。
- 下一步：point-in-time 股票/基金池、更多数据源、执行滑点与冲击成本建模、每日再平衡与周度再平衡的对照实验。
